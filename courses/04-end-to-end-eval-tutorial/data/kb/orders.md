# Orders

## Order statuses
"Processing" means the order is being packed and can still be changed. "Shipped" means it has
left the warehouse and has a tracking number. "Delivered" means the carrier confirmed delivery.
"Cancelled" means the order was stopped before shipping and has been refunded.

## Changing or cancelling an order
An order can be changed or cancelled within 1 hour of being placed, while its status is
"Processing". After that, wait for delivery and start a return instead.

## Changing the delivery address
The delivery address can be changed only before the order ships. Once an order is "Shipped",
the address cannot be changed by us; the customer can contact the carrier using the tracking
link.

## Order confirmation
An order confirmation email is sent within 15 minutes of purchase. Check the spam folder if it
does not arrive. The order ID starts with "PC-" followed by five digits.
