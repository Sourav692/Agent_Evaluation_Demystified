# Week 1 dataset

| File | What it is |
|---|---|
| `cases.jsonl` | The 30 labeled cases, `case-0001` to `case-0030`. Generated by `datasets/build_datasets.py`. Do not edit it by hand. |

Each line of `cases.jsonl` is one case:

| Field | Meaning |
|---|---|
| `case_id` | Stable ID. Week 2 keeps the same IDs |
| `message` | What the customer typed |
| `customer_id` | The signed-in, verified customer |
| `slice` | The condition the case tests, such as `damaged_expired` |
| `expected_outcome` | The label: `refund_created`, `refund_denied`, `escalated_to_human`, `access_denied` or `clarification_requested` |
| `required_keywords` | Phrases the reply must contain |
| `forbidden_actions` | Tool calls that must not happen |

This week also reads `shared/support_agent.py` (agent v1), `datasets/world.json` (customers and orders) and `datasets/policies/refund-policy-2026-01.md`.

All data is synthetic. No real customers, orders or payments.
