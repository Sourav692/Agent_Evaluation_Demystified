# Changelog

What changed on the site, newest first. One entry per change a reader would notice.

## 2026-10-15

- Every roadmap explainer now ends with a "Practise it" section linking its labs and
  notebooks, with a shortcut to it under the reading time.
- The home page now says who the site is for and where to start: "Start at Level 0", or
  "Interviewing this week?" for the fast path, with three ways in below.
- The roadmap, the study plan and Level 0 now say which path each is (learning, about 54 h;
  interview, about 20 h) and link each other. The roadmap lists Level 10, the cram sheet.
- Check Yourself answers on every explainer now sit behind "Show answer", so you can try
  each question first.
- Diagrams load as you scroll to them, so long pages show their text sooner.
- The metric questions in the question bank are numbered by section (10.1 Q1, 10.2 Q1), so
  no two questions share a number. Explainer references no longer cite a file that doesn't exist.
- Links to another page on the site read as that page's title, not a repository path.
- The cost and case-study pages show dollar amounts, dashes and their cost tables
  correctly.
- Added an [About](about.md) page and this changelog.
- Every page now has a footer naming the maintainer and the date the page last changed,
  with links to edit it on GitHub or report an issue.
- Shared links show a preview card with the site's image; pages carry a canonical URL.
- Unknown addresses show a page-not-found page with links back into the site.
- Added `robots.txt` and `sitemap.xml`.
- Section links (`#…`) now land on the right heading, on the site and on GitHub alike.
  Section ids changed to GitHub's form, so an old site link to a section with a dash
  in its title may land at the top of the page.
- No page scrolls sideways on a phone; wide lab tables scroll inside their own box.
- Fonts are served from the site itself instead of Google Fonts.
- Each long document has one main heading; its parts sit one level below.
- Lab 03's code uses DeepEval 4's `SingleTurnParams`.
- The study plan's drill links open the drill instead of GitHub.
- Repository paths written as code now link to the file on GitHub.
- Added a share preview image and a favicon.
- Published the support-system case study and its cost and guardrails companion.
- Published the topic-to-notebook mapping.
- The roadmap gained a Core path, and every level now shows a five-part Path line.
- The online-judge sampling rate reads 2–5% of traffic on every page.
- The field guide, the explainers and the question bank absorbed topics from retired
  material, so nothing on the site points into the archive any more.
